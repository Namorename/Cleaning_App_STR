# Запуск на iPhone — чек-лист владельца

**Составлен в ночь 2026-10-09.** Решение 6 (`docs/design/decisions.md`, владелец 2026-09-27):
iOS обязателен к запуску — у большинства горничных iPhone, раздача — APK и TestFlight. Сборки iOS
ещё не было ни одной. Здесь — всё, что владелец делает сам, точными командами, и что нужно для
рецензии Apple. Входы в Apple и Expo, сборки и отправки — только в окне владельца: `eas-cli` без
терминала меню и вход Apple не проходит.

## 0. Что уже готово в коде

- `bundleIdentifier` `cz.strops.cleaner`, `buildNumber` растёт сам (`autoIncrement` в профиле).
- Версия **1.2.0**, название под иконкой «woom», иконка — знак «Абрикоса» в трёх формах (светлая,
  тёмная, тонированная: `assets/images/ios-*.png`), заставка светлая и тёмная.
- Профили (`apps/mobile/eas.json`): **`field-ios`** — сборка для горничных, канал `field` (обновления
  по воздуху горничным идут в ветку `field`), окружение EAS `production`; `testflight` — пробная сборка
  на канале `preview`. У обоих образ `macos-tahoe-26.5-xcode-26.6` закреплён — SDK 57 не подключает
  сцены UIScene, а сборка на Xcode 27 без них не запускается на iOS 27 (Apple TN3187). Переход — с
  SDK 58, до апреля 2027. Если в окружении `production` нет `EXPO_PUBLIC_SUPABASE_URL` и ключа, сборка
  остановится в начале с понятной ошибкой (`app.config.ts`, `checkBuildEnv`) — тогда переменные
  завести командами раздела 1 ранбука F11 для окружения `production`.
- `usesNonExemptEncryption: false` — App Store Connect не задаёт вопросов об экспорте шифрования.
- Право `time-sensitive` для срочных push.
- Тексты разрешений камеры, микрофона и фото на ru, en, cs (`locales.<язык>.ios`).
- Ключ APNs вручную не создаётся: EAS создаёт его на первой сборке.
- Apple Developer Program оплачен, статус Active (2026-10-08); продление до 2027-10-05.

## 1. Из какого коммита собирать

Сборка iOS — из того же коммита, что и Android 1.2.0: ветка `phone-1-2-0`, влитая в `main`
коммитом «натив + 1.2.0» (слово владельца). До этого — только сборка для проверки, не для раздачи.

## 2. Команды (PowerShell, из папки приложения)

```powershell
cd "$env:USERPROFILE\Desktop\Cleaning App\apps\mobile"
git status                      # ветка и чистое дерево
npx eas-cli whoami              # аккаунт namorenames-team; если нет — npx eas-cli login
```

### 2.1 Первая сборка

```powershell
npx eas-cli build -p ios --profile field-ios
```

Ответы на вопросы:
- вход Apple ID, код 2FA, выбор команды (Individual);
- «Generate a new Apple Distribution Certificate?» — **да**;
- «Generate a new Apple Provisioning Profile?» — **да**;
- «Setup Push Notifications for your project?» — **да** (EAS создаст ключ APNs).

Если сборка упала на `time-sensitive`: developer.apple.com → Certificates, Identifiers & Profiles →
Identifiers → `cz.strops.cleaner` → включить **Time Sensitive Notifications** → собрать снова. Сборка
идёт 20–40 минут, в логе должно быть Xcode 26.x.

### 2.2 Отправка в TestFlight

```powershell
npx eas-cli submit -p ios --profile field-ios --latest
```

Первая отправка создаёт запись приложения в App Store Connect: название (уникальное во всём
магазине; «woom» почти наверняка занято — например «woom team»; под иконкой всё равно будет «woom»
из сборки), основной язык, SKU (любое, например `strops-cleaner`). Через 10–15 минут сборка
появится в App Store Connect → TestFlight.

### 2.3 Ключ App Store Connect API (по желанию)

После записи приложения — чтобы следующие сборки и отправки шли без 2FA:

```powershell
npx eas-cli credentials -p ios
```

→ «App Store Connect: Manage your API Key» → создать.

## 3. Внутренний TestFlight (без рецензии Apple)

App Store Connect → TestFlight → Internal Testing → «+» группа → добавить себя (и только
пользователей App Store Connect). На iPhone — приложение TestFlight из App Store → «woom» →
установить. Проверки — раздел 5.

## 4. Внешний TestFlight — горничным (рецензия Apple)

App Store Connect → TestFlight → External Testing → «+» группа → сборка → **Test Information**:

- **Beta App Description** — что это: приложение для сотрудников компании краткосрочной аренды
  (уборки, задания, расходники); вход только по учётке от менеджера, регистрации нет.
- **Feedback Email** и **контакт** (имя, телефон, почта) — вводит владелец; в репозиторий не пишутся.
- **Sign-in required → да, демо-учётка** (раздел 4.1).
- **Privacy Policy URL** — страница `/privacy` панели (раздел 4.2).

«Submit for Review» → обычно меньше суток. После одобрения — публичная ссылка группы или приглашения
по почте; горничная ставит TestFlight, открывает ссылку, ставит «woom». Сборка TestFlight живёт
**90 дней** — напоминание на 75-й день: пересобрать.

### 4.1 Демо-учётка для рецензента

Рецензент Apple входит и смотрит приложение. Реальная компания — это настоящие брони, имена гостей и
коды дверей, поэтому рецензенту нужна **отдельная демо-компания** (свой `host` — мультитенантность
это держит, F14) с горничной, двумя объектами, парой уборок с шагами и одним заданием, без настоящих
данных. Завести её — запись в облако: делается по слову владельца (скрипт можно подготовить заранее).
После одобрения учётку можно отключить в панели и включить снова к следующей рецензии.

### 4.2 Политика конфиденциальности

Решение 17 (`docs/f11-plan.md`): публичная страница на домене панели, без входа; чешский основной,
плюс английский и русский. Черновик — `docs/privacy-policy-draft.md`; **реквизиты оператора (имя или
фирма, IČO, адрес, контакт) даёт владелец**. Страницы `/privacy` в панели пока нет — её нужно сделать и
выкатить до отправки на рецензию (Vercel, без сборки телефона).

## 5. Что проверить на iPhone

- Два холодных запуска; вход; выход.
- Иконка на рабочем столе — светлая, тёмная, тонированная; название «woom» при русском и чешском
  языке системы; заставка в светлой и тёмной теме.
- Разрешения камеры, микрофона и фото — текст на языке системы; отказ — понятный экран, а не вылет.
- Шаг с фото; шаг с видео: запись до предела компании, просмотр, «Переснять», отправка по мобильной
  сети, сворачивание приложения во время загрузки и продолжение после возврата.
- Push: разрешение, приход при закрытом приложении, нажатие из закрытого (холодный старт) и из фона
  открывает нужный экран; срочный push пробивает «Фокус».
- Тёмная тема, самый крупный шрифт системы, VoiceOver на главных экранах.
- Без связи: действие встаёт в очередь и уходит после появления сети.
- Роли: горничная, техник, главный техник — каждая видит свои вкладки.

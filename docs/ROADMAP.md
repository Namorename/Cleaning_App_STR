## Расхождения модели данных

Закрывать пока миграций мало: 18 файлов, 7 таблиц в `public`, 19 политик.

| Расхождение | Наше сейчас | Нужно | Когда |
|---|---|---|---|
| Тенант | нет | `host_id` во всех прикладных таблицах | F14, до F7 |
| Окно уборки на задаче | один `due_at`, и только у same-day | `time_from` / `time_to` из окна объекта — у каждой задачи | F15 |
| Число гостей | нет | `guests_count` заезжающей брони, read-only | F15 |
| Промежуточная уборка | нет в enum типов | `midstay` рядом с `cleaning` | F15 |
| Кто выполнил | только `assignee_id` | `completed_by` — может отличаться | F15 |
| Заметки объекта | нет | `cleaner_notes` (видит клинер) и `internal_notes` (не видит) | F15 |
| Приоритет в привязке | только `mode` (auto/claim) | `+ priority int` для стратегии «по приоритету» | F15 |
| Название ручного задания | нет | `title` ≤ 30 символов | F10 |
| Статус объекта | `is_active boolean` | enum `active / maintenance / archived` | F10 |
| Порядок в календаре | нет | `sort_order` | F10 |
| Связанные листинги | таблица M:N `property_links`, пустая | у объекта один родитель — либо `parent_id`, либо оставить M:N осознанно | F10, см. `docs/linked-listings.md` |
| Корректировка длительности | нет | `duration_override_min` с сохранением исходного замера | F12 |
| Коды доступа | внутри `name` из Hostaway | структурные поля объекта | F10 |
| Конфликт с PMS | нет | флаг на задаче | F23 |

Наши надстройки над спецификацией — не расхождения, оставляем: девять статусов задачи вместо
пяти, конечный `expired`, горизонт и запас по времени, `is_block` на брони.

## Известные подводные камни

| Риск | Митигация |
|---|---|
| Связанные листинги (`571441 = 566761 + 566769`) дают дубли задач | Таблица маппинга родитель↔дети, проверка в F4 |
| Rate limit Hostaway 15 запросов / 10 сек | Инкрементальный синк, курсоры, экспоненциальный backoff |
| Часовые пояса объектов | Хранить tz на объекте, дедлайны считать в локальном времени |
| Утечка secret key в бандл | Проверка в CI на `EXPO_PUBLIC_.*SECRET` |
| Объём видео | 720p / 30 с, retention 90 дней |
| Конфликты офлайн-правок | Очередь мутаций с F6, журнал изменений |
| Блокировки календаря приходят как брони («Boiler - ремонт») | `is_block` + настраиваемый список служебных имён; уборку по ним не создавать |
| Правка `_shared/` в Edge Functions | Перед деплоем смотреть `git show --stat` и передеплоивать все функции, которые модуль бандлят |
| Цена мультитенантности растёт с числом политик | F14 до F7, пока политик 19 |
| Календарь на 109 строк × 30 дней | Виртуализация строк, закреплённые шапка и первая колонка, предзагрузка соседних диапазонов |

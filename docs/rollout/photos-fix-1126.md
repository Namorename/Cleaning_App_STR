# Фото техника не видны офису — исправление 26.11.2026

`CORE`. Запрос владельца 26.11: в панели на задании «Sofa/gauč» (выполнено 26.11 13:26, техник
отметил в приложении) не было фото техника, хотя на его телефоне шаг «Фото проблемы» показывал два
загруженных фото.

## Причина (подтверждена данными)

- Файлы записаны верно. Задание `5b528129-b8cb-4116-afe1-46f604c7931e`, работа техника — задача
  `f56880a7-b680-4573-912a-a1a566508b83` (`maintenance`, `done`, начата 12:25:57, завершена
  12:26:43 UTC). Два фото — строки `task_media` с `task_id = f56880a7…` и `step_id` шага, загрузка
  подтверждена (`uploaded_at`), не удалены и не вычищены; объекты лежат в бакете `task-media` по пути
  `<host>/<task_id>/<media_id>.jpg`.
- Права в порядке: `is_manager()` (manager, admin, reception) читает все `task_steps` и
  `task_media`, главный техник — шаги и файлы ремонтов; объект хранилища читается по строке.
- Дефект показа, с F10 (09.09):
  - панель рисовала шаги и файлы только у «живой» работы (`liveFixTask` — не `done`, `cancelled`,
    `expired`). Техник заканчивает работу через минуту после фото, поэтому у выполненной работы блок
    «Работа техника» показывал только «Выполнил»;
  - телефон показывал шаги работы только её исполнителю (кнопка «Открыть работу техника»); офис на
    экране задания их не видел вовсе.
- Выкатка 26.11 «фото, видео и комментарий менеджера» тут ни при чём: она не трогала чтение файлов
  работы, а пачки менеджера — отдельный владелец (`addition_id`).

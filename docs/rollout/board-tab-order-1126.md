## Откат (обратный порядок)

1. Панель: `git revert` коммитов этой ветки в `main` (или в Vercel сделать текущим прежний
   прод-деплой).
2. База: `docs/one-off-writes/board-tab-order-rollback.sql` (`supabase db query --linked -f`), затем
   `npx supabase migration repair --status reverted 20261126160000 --linked`. Сохранённые порядки
   теряются, у всех снова порядок по умолчанию.

Репетиция: `node docs/rollout/rehearsal-board-tab-order-1126.mjs` (временная база у головы облака,

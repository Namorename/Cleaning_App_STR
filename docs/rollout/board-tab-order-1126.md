Устройство — `docs/manager-boards.md`, раздел «Личный порядок вкладок». Промпт владельца 26.11
разрешил выкат целиком; заранее названное слово «выкатывай порядок досок» покрывает миграцию и
перемотку `main` (Vercel выкатывает панель сам). Функции и OTA не нужны: телефон и API не менялись,
`openapi.v1.json` и каталог MCP после `npm run api:docs` те же.

таблицы (после отката базы), показывает вкладки по умолчанию и молчит.

## Порядок и заставы

1. **Чтение состояния** (`cloud-read.mjs`): голова облака `20261126150000`; проба
   `probe_board_tab_order_1126.sql` = «до» (таблицы и функций нет).
2. **Миграция под заставой, одна** (не в окне 03:00–04:40 UTC): sha256 файла = записанному, голова =
   `20261126150000` (`HEAD_WANT`), сухой прогон называет ровно `20261126160000_board_tab_order.sql`;
   затем `db push`. Проба = «после» репетиции; права таблицы через `aclexplode`: у `authenticated` —
   INSERT, SELECT, UPDATE, у `anon` и PUBLIC — ничего; `migration list --linked` = репозиторий.
3. **`main` ff-only** → Vercel Production Ready, `/login` 200.

Если проба провалилась или сборка Vercel упала — откат в обратном порядке (ниже) и отчёт.

## Откат (обратный порядок)

1. Панель: `git revert` коммитов этой ветки в `main` (или в Vercel сделать текущим прежний
   прод-деплой).
2. База: `docs/one-off-writes/board-tab-order-rollback.sql` (`supabase db query --linked -f`), затем
   `npx supabase migration repair --status reverted 20261126160000 --linked`. Сохранённые порядки
   теряются, у всех снова порядок по умолчанию.

Репетиция: `node docs/rollout/rehearsal-board-tab-order-1126.mjs` (временная база у головы облака,
накат → откат → накат, все SQL-наборы на всех миграциях).

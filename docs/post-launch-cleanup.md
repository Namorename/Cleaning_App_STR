## Не мёртвое, хотя похоже

- **`expo-symbols`** — наши файлы его не импортируют, но это прямая зависимость `expo-router`
  57.0.24, и `expo-router` требует его в `native-tabs/utils/materialIconConverter.android.js`, куда
  ведёт импорт из `layouts/withLayoutContext.js` (его использует каждый наш макет). Автолинковка Expo
  идёт по зависимостям вглубь: модуль останется в сборке и без строки в нашем `package.json`, а
  убранная строка лишь спрячет зависимость. Не убирать (проверено 2026-10-09).
- **`assets/images/favicon.png`** — шаблонная, но на неё ссылается `app.json` (`web.favicon`).

## Отложено до после запуска

- Шапка «Чат · место» в чате телефона — нужен новый запрос (место разговора).
- Кадр чужих списков: если сессия приходит между восстановлением кэша и чтением метки владельца,
  на один кадр могут мелькнуть списки предыдущего человека — нужен `useIsRestoring()` в маршруте
  (экранная правка, по воздуху).
- Фото при молчащем хранилище и живом Auth ждут без конца (давнее поведение, вне видео).
- Медленная загрузка видео (< ~84 кбит/с вверх) падает примерно через 34 минуты — сказать это в
  тексте ошибки.
- Сверочный обзор правок очереди 09.10 (`7553530..8a58d77`), LOW — по воздуху:
  - флажки «срез» доски пишутся побочным действием чтения: отменённое старое чтение, закончившись
    позже нового, может оставить старый флажок до следующего обновления (`features/board/use-board.ts`,
    счётчик чтений или запись только из принятого чтения);
  - повтор отложенной «парковки» берёт человека на момент постановки, а не исполнения: в узком окне
    смены человека его свежие действия уйдут в хранилище и сразу вернутся (повтор безопасен —
    вызовы идемпотентны; `move-queue.ts`, читать текущего человека в шаге).
- Обзор очереди 09.10, L5 (отложен как не малый): многозапросное действие (загрузка видео,
  чтение после хода) берёт ту сессию, что есть в эту секунду; сервер не даёт чужому писать
  (`created_by = auth.uid()`), но правильная пауза «сменилась сессия» — отдельная правка
  `retryMove` и `attach-retry`.
- Повтор «Взять» после переноса офисом на другой день проходит молча (в переменных хода нет дня и
  места, сравнить не с чем); нужно, если владелец захочет уведомление.

## После запуска — план владельца 2026-10-10 (блок 7)

### 1. Письма Supabase через Gmail

Сейчас «Send password recovery» в Supabase (Authentication → Users) отвечает **«Error sending recovery
email»**: письма из Auth не уходят. Порядок:

1. **Найти причину в Auth logs** (Dashboard → Logs → Auth): строка ошибки SMTP при отправке — отказ
   входа, порт, TLS, отправитель. Без лога настройки не трогать.
2. **Настройки SMTP** (Authentication → Emails → SMTP Settings) под Gmail: хост `smtp.gmail.com`,
   порт **465** (SSL) или **587** (STARTTLS), пользователь — полный адрес Gmail, пароль — **пароль
   приложения** Google (нужна двухэтапная проверка; обычный пароль Gmail не подойдёт), отправитель —
   тот же адрес. Gmail режет объём (сотни писем в сутки) — для сброса паролей сотрудников хватает.
   Site URL и Redirect URLs там же — проверить, что в них нет старого
   `cleaning-app-str-web-xi.vercel.app` (ссылка в письме ведёт туда).
3. **Затем — письмо с временным паролем из панели.** Сейчас «Сбросить пароль» в «Команде» показывает
   временный пароль менеджеру в окне. Следующий шаг — серверное действие панели (Next.js на Vercel,
   Node.js) отправляет его сотруднику письмом через тот же SMTP: Vercel Functions выпускают исходящие
   соединения на 465 и 587 (25 закрыт). Учётные данные SMTP — только серверные переменные Vercel, не
   `NEXT_PUBLIC_*`. Тест сначала (отправка подменяется), текст письма — по языку сотрудника.

### 2. Адрес панели: короткий vercel.app и свой домен

Боевой адрес с 10.10 — `https://woom-bnb.vercel.app` (проект Vercel `woom`). Свой домен: купить,
добавить в Vercel (Project → Domains), записи DNS у регистратора, дождаться сертификата. После
переезда — Supabase Auth (Site URL, Redirect URLs), Privacy Policy URL в App Store Connect (и Google
Play, если будет), `README.md`, `docs/dev-notes.md`, `docs/ios-launch-checklist.md`.

### 3. Vercel Pro и Supabase Pro

- **Supabase Pro:** ежедневные бэкапы (на Free их нет — `docs/launch-reset.md`, шаг 0), PITR как
  дополнение, предел загрузки файла выше 50 МБ (видео до настройки компании, сейчас 60 МБ при
  пределе хранилища 50), обновление PostgREST (401 «JWT issued at future», память
  `postgrest-upgrade-postcheck`), проект не засыпает при простое.
- **Vercel Pro:** тариф Hobby — для некоммерческого использования; панель компании — коммерческая.
  Плюс доступ команды к превью и журналам.

### 4. Подтверждения в панели, которых ещё нет

Список 10.10 (`docs/launch-phone-plan.md`, «Команда»): **«Объекты → Клинеры» → «Убрать»** снимает
привязку сразу, без вопроса (тот же `ConfirmDialog`, что в «Команде»); **«Выслать другой»** в окне
нового пароля сбрасывает пароль ещё раз без вопроса. Оба — диалог с именем, фокус на «Отмена», три
языка, тест.

### 5. Отзыв токена Sentry

Токен чтения `~/.str-ops/sentry-read-token.txt` (выдан 10.10 для разбора пустого экрана) отозвать в
Sentry (User Settings → Personal Tokens), файл удалить, пин `scripts/sentry-get.mjs` и разрешение в
`settings.local.json` снять — владелец.

### Ещё с 10.10

- **«Макс. размер» видео ≤ 50 МБ**, пока Supabase на Free: в настройках компании 60 МБ; телефон держит
  50 сам, но сервер примет регистрацию файла 50–60 МБ, загрузка которого упадёт с 413.
- **Время съёмки видео из галереи** пишется моментом выбора (`capture.ts`), а не датой файла —
  подтвердить или читать дату из метаданных.
- **Длина видео из галереи** показывается с тысячными («47.867 с») — округлять до десятых, как у камеры.
- **`task/[id]/index.tsx`** ещё задаёт заголовок через `<Stack.Screen options>` (перерисовка раз в
  30 с) — перевести на `useScreenTitle`, как экран шага.
- **Source maps OTA** в Sentry не выгружены (`npx sentry-expo-upload-sourcemaps dist` в окне владельца).
- **`/privacy`:** 11 значений `PRIVACY_SETTINGS` (`apps/web/src/app/privacy/settings.ts`) пустые — на
  странице плейсхолдеры «[вписать: …]»; регионы известны: Vercel Functions — `iad1` (Вашингтон, США),
  Sentry — EU (`de.sentry.io`).
- **Демо-объект Apple** (`900000000001`) и демо-горничную убрать, когда внешний TestFlight больше не
  нужен рецензенту.

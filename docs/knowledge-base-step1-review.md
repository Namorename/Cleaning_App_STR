# База знаний, шаг 1 — независимый обзор (2026-10-17)

Три новых агента `ecc:code-reviewer`, каждому только дифф `804ac7a..107bc5e` своей части и
код; документы, `.claude/` и история коммитов закрыты. Части: база (миграция, наборы,
откат, проба, типы), разборщик и раздел панели, доступ главного техника. **CRITICAL и
HIGH — нет ни в одной части.** Ниже — что найдено и что с этим сделано (коммиты после
107bc5e).

## База

| Находка | Что сделано |
|---|---|
| M1: проверка «экран старше» сравнивала только версию текста — чужая правка мест молча затиралась | маркер — `updated_at` (двигает любая запись): `p_expected_updated_at timestamptz default null` у `save_kb_article` и `restore_kb_revision`; тест «даже если меняются только места» |
| L1: повтор своей же правки после потерянного ответа — «кто-то сохранил» | если хранится ровно присланное тем же автором — это его запись, отказа нет; тест и обратный тест (тот же текст коллеги — конфликт) |
| L2: `rev_stamp` выдаёт счётчик транзакций | хранится md5 штампа; тест |
| L3: два оператора одним простым сообщением — одна версия | оговорка в шапке миграции |
| L4: `current_host_id()` без `(select …)` в политиках | обёрнут |
| L5: `kb_checked_translations` `immutable` при чтении enum; языки зашиты | `stable`; языки из `app_language` |
| L6: пробелы в тестах | добавлены: `in_progress` / `blocked` / `paused` и `expired`, работа в комнате открывает здание, часть дома закрыта, запись `service_role`, пустая версия не возвращается поверх опубликованной (набор 90/90) |

## Разборщик и панель

| Находка | Что сделано |
|---|---|
| M1: отказ публикации новой статьи не виден — форма перемонтировалась | адрес новой статьи меняется только после всего действия; тесты «отказ виден, адрес new» и «после публикации — по id» |
| M2: обновление по фокусу окна или чужое сохранение молча стирало набранное и обходило проверку версии | форма привязана к id, основа и маркер — в её состоянии; «Загрузить последнюю версию» и возврат версии берут данные сервера явно; тест |
| M3: две квадратичные дорожки разборщика (хвост пробелов, голые `https://`) | `trimEnd`, потолок сканирования адреса; тесты на четыре таких строки |
| L4: невидимые, bidi и полноширинные символы в адресе | отвергаются; хост рядом со ссылкой — в punycode |
| L5: скобки в адресе обрезали ссылку | скобки по балансу; тест |
| L6: пробел в конце заголовка — вечное «есть несохранённые» | сравнение по обрезанным заголовкам |
| L7: места вне доступа терялись при переключении «где показывать» | места сохраняются при любом переключении |
| L8: перевод с заголовком без текста прятал текст оригинала | такой перевод не выбирается; тест |
| L10: U+2028 ломал пункт списка | `[\s\S]` в выражениях |
| L11: `radiogroup` без имени, `toolbar` без стрелок, кнопки 36 px, неиспользуемый ключ `saved` | `fieldset` с `legend`, группа кнопок, 44 px, «Сохранено» показывается |
| L11: «Все статьи» при несохранённых правках уходит без вопроса | **не сделано** — см. вопросы в отчёте |
